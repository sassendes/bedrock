What one command builds

Each layer sits on the one below and assumes the one above can be broken into.

  1. RuntimeFalco watches every node for shells and odd file reads. Reloader picks up config changes.
  2. ObservabilityMetrics and logs and traces with alerting from the first boot.
  3. SecretsOpenBao hands each pod its own secrets as files in memory. The app's database password rotates every day.
  4. DataThree PostgreSQL clusters. A primary with synchronous replication plus a live replica and one that runs five minutes behind.
  5. StorageEvery volume encrypted with LUKS. Object storage for backups encrypted at rest.
  6. AdmissionOnly allowlisted images pinned by digest can run. Pod Security and Kyverno check everything else.
  7. NetworkDefault deny everywhere. Every plain HTTP call is checked at layer 7 and traffic between nodes is encrypted.
  8. KubernetesRKE2 with the CIS profile and audit logging and secrets encrypted in etcd.

Failover that waits for proof

Most setups promote a replica when a timeout runs out. bedrock promotes only when the evidence says the primary is gone.

  1. Postgres signs its own heartbeat. Two observers on every node write to the primary and have it sign a fresh challenge.
  2. No observer votes alone. One that cannot reach the primary asks its peers first. A login refused counts as alive.
  3. A verifier checks the witnesses. Three of four must agree the primary is dead and the candidate must be a live replica in sync.
  4. Admission opens the door. Only the decider that holds the lease can touch a database and only after the verifier signs off.
